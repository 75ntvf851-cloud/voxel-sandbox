# VoxelSandbox - Controls

## Управление (Russian)

### Движение
- **W, A, S, D**: Движение (вперед, влево, назад, вправо)
- **Мышь**: Обзор камеры
- **Пробел**: Прыжок
- **F**: Переключить режим полета
- **Shift** (в полете): Снижение
- **Shift** (на земле): Бег (будущая функция)

### Строительство
- **1**: Режим постройки
- **2**: Режим удаления блоков
- **3**: Режим осмотра
- **R**: Повернуть блок (шаг 90°)
- **ЛКМ** (Левая кнопка мыши): Разместить/удалить блок
- **ПКМ** (Правая кнопка мыши): Отменить действие

### Вода (отладка)
- **Ctrl + ЛКМ**: Добавить воду в целевую ячейку
- **Ctrl + ПКМ**: Удалить воду из целевой ячейки
- **P**: Пауза симуляции воды

### Система
- **Esc**: Пауза / Меню
- **F3**: Переключить отладочную панель
- **F9**: Переключить язык (RU ↔ EN)
- **F12**: Скриншот (будущая функция)

## Controls (English)

### Movement
- **W, A, S, D**: Move (forward, left, backward, right)
- **Mouse**: Camera look
- **Space**: Jump
- **F**: Toggle fly mode
- **Shift** (while flying): Descend
- **Shift** (on ground): Sprint (future feature)

### Building
- **1**: Build mode
- **2**: Remove mode
- **3**: Inspect mode
- **R**: Rotate block (90° step)
- **LMB** (Left Mouse Button): Place/remove block
- **RMB** (Right Mouse Button): Cancel action

### Water (Debug)
- **Ctrl + LMB**: Add water to target cell
- **Ctrl + RMB**: Remove water from target cell
- **P**: Pause water simulation

### System
- **Esc**: Pause / Menu
- **F3**: Toggle debug overlay
- **F9**: Toggle language (RU ↔ EN)
- **F12**: Screenshot (future feature)

## Tips / Советы

### RU
- Используйте режим полета (F) для быстрого перемещения по миру
- Создайте контейнер из блоков и добавьте воду для тестирования физики
- Отладочная панель (F3) показывает FPS и текущий режим
- Сохраняйте игру часто через меню (Esc)

### EN
- Use fly mode (F) for quick world navigation
- Build a container from blocks and add water to test physics
- Debug overlay (F3) shows FPS and current mode
- Save game frequently via pause menu (Esc)
